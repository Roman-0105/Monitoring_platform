# Monitoring_platform

Два независимых веб-приложения для предприятия «РГ Голд» (карьер ЮРГ),
каждое в своей папке:

| Папка | Проект | Что делает |
|---|---|---|
| [`hydro-monitoring/`](hydro-monitoring/) | Гидрогеологический мониторинг | Карта скважин/точек наблюдения, уровни воды, водоотлив, пылеподавление, отчёты, канавы — исходный проект. |
| [`risk-inspection/`](risk-inspection/) | Инспекция участков | Журнал обращений по рискам на участках, карта с точками/геологией, отчёты — см. `risk-inspection/README.md` и `risk-inspection/BACKEND_INTEGRATION.md`. |

Оба — статические SPA без сборки (открываются напрямую или через любой
статический HTTP-сервер), с отдельными `index.html`, стилями и JS в
каждой папке. Общее — только `node_modules`/`package.json` в корне
(сейчас единственная зависимость — `playwright`, используется для
ручного/агентского тестирования обоих проектов через Playwright, в
самих приложениях не участвует).

## Запуск локально

```bash
cd hydro-monitoring && python3 -m http.server 8080   # Гидрогеологический мониторинг
# или
cd risk-inspection && python3 -m http.server 8080    # Инспекция участков
```
