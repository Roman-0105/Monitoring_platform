9.6 Живая P&ID-схема водоотливного комплекса

Интерактивная SVG-схема с анимацией потоков
Реализация: SVG строится из конфигурации карьера (позиции зумпов/насосов из БД). Анимация потоков — CSS stroke-dashoffset. Данные обновляются через Supabase Realtime. Таблицы: dewatering_units(id, quarry_id, type, name, x, y, capacity), dewatering_readings(unit_id, ts, flow_m3h, level_m, pressure_mpa, status).
Приоритетный план реализации:
1. Карта — Вариант А (фильтр-бар) — минимум изменений, максимум пространства карте
2. Точки — Вариант А (master-detail) — ускоряет работу с журналом точек
3. Водоотлив 9.1 — пороги и оповещения — критически важно для безопасности
4. Водоотлив 9.3 — учёт ТО насосов — снижает риск аварий
5. История — Вариант А (calendar heatmap) — навигация по данным
6. Водоотлив 9.4 — цифровой сменный рапорт — замена бумажного журнала
7. Водоотлив 9.2 + 9.6 — водный баланс и SVG-схема — аналитические инструменты
8. Водоотлив 9.5 — суточный экспорт — автоматизация отчётности
