Текущее состояние

Вкладка «Водоотлив» сейчас показывает только аналитику расчётов — графики Chart.js с фильтром по периоду и карьеру. Нет оперативной информации о насосах, уровнях, тревогах. Диспетчер не видит текущую ситуацию — только исторические данные.
