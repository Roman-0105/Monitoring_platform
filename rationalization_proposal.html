Цифровая платформа мониторинга шахтных вод
карьера ЮРГ компании RG-Gold

Автоматизация сбора, хранения, аналитики и ИИ-отчётности гидрогеологических данных

1. Суть предложения

Предлагается внедрение специализированной веб-платформы для автоматизации сбора, хранения, визуализации и аналитической обработки данных гидрогеологического мониторинга карьера ЮРГ. Платформа заменяет бумажный документооборот и ручную обработку данных в таблицах на единую цифровую среду с интерактивными картами, структурированной базой данных, аналитическими инструментами в реальном времени и автоматической генерацией профессиональных отчётов на основе искусственного интеллекта.

2. Существующее положение дел

До внедрения платформы процесс мониторинга шахтных вод включал следующие этапы, каждый из которых нёс риски снижения качества данных:

  • Обходчики фиксировали замеры в бумажных журналах или в произвольных таблицах Excel
  • Перенос данных в сводные документы производился вручную — основной источник ошибок при переписке показаний
  • Отсутствовала единая база данных: информация по разным обходам хранилась в разрозненных файлах
  • Анализ трендов и сравнение периодов требовали значительных временных затрат специалиста
  • Местоположение точек мониторинга не было привязано к актуальной горной карте
  • Руководство не имело оперативного доступа к данным о гидрогеологической обстановке
  • Формирование отчётов занимало значительное рабочее время гидрогеолога при высоком риске несоответствия текста реальным данным

3. Концепция платформы

Цифровая платформа мониторинга шахтных вод — это браузерное веб-приложение, работающее на основе облачной базы данных. Доступ осуществляется с любого устройства (ПК, планшет, смартфон) без установки программного обеспечения. Платформа реализована на основе стека современных открытых технологий: JavaScript, HTML5, PostgreSQL (Supabase), Anthropic Claude API.

Архитектурные принципы: единая централизованная база данных · ролевая система доступа (администратор / гидрогеолог / наблюдатель) · интерактивная геопривязанная карта как основа интерфейса · автоматическое формирование аналитики при внесении данных · работа в браузере без установки ПО

4. Возможности платформы

4.1 Модуль «Карта мониторинга»

  • Интерактивная карта с нанесёнными точками мониторинга и горизонтальными скважинами
  • Цветовая индикация статуса каждой точки в реальном времени: Активная / Паводковая / Иссякает / Пересохла / Новая
  • Визуальный прогресс текущего обхода — замеренные точки (зелёный цвет), незамеренные (серый)
  • Тепловая карта дебитов (Heatmap): распределение водопритоков по площади карьера
  • Фильтрация по дате мониторинга, домену, борту, горизонту

4.2 Модуль «Точки интереса»

  • База точек мониторинга с паспортными данными: номер, домен, борт, горизонт, координаты
  • Внесение замеров: дебит (л/с, м³/ч), статус, ответственный, комментарий, фотофиксация
  • Полная история измерений по каждой точке с графиками динамики

4.3 Модуль «Скважины»

  • Учёт горизонтальных дренажных скважин: глубина, азимут, угол наклона, горизонт, борт
  • Замеры дебита с привязкой к неделе мониторинга
  • Статусная система: Активная / Иссякает / Сухая

4.4 Модуль «Аналитика»

  • KPI-панель: суммарный дебит (точки + скважины), покрытие обхода, иссякающие точки — с динамикой к предыдущему периоду
  • График тренда дебита за 12 обходов с плавными кривыми и зонами заливки
  • Система алертов: автоматическое выявление резкого роста дебита, незамеренных точек, смены статуса
  • Распределение по 8 бортам карьера с визуализацией вклада каждого борта
  • Матрица Домен × Статус — структурный анализ по областям карьера
  • Таблица горизонтов — сравнение дебитов за 3 периода
  • Аналитика скважин: рейтинг по дебиту, тренды, KPI за неделю
  • Экспорт данных в CSV и Excel (XLSX)

4.5 Модуль «Автоматическая отчётность с ИИ-анализом» — ключевая инновация

Платформа включает полностью автоматизированный модуль формирования гидрогеологических отчётов. При нажатии одной кнопки система самостоятельно выполняет весь цикл подготовки отчёта:

  1. Сбор данных — загружает замеры по выбранному периоду (или двум для сравнения): статистику по точкам, горизонтам, доменам, бортам
  2. Захват схемы карьера — автоматически формирует снимок интерактивной карты с нанесёнными точками мониторинга за выбранную неделю
  3. Загрузка фотоматериалов — подтягивает фотофиксацию точек из облачного хранилища
  4. ИИ-анализ (Claude AI) — отправляет фактические данные в языковую модель и получает профессиональный гидрогеологический вывод
  5. Сборка готового отчёта — формирует структурированный документ, готовый к печати и рассылке
Банк промптов — настраиваемые инструкции для ИИ
Специалисты сами формулируют и сохраняют задания для ИИ в «Банке промптов». Встроенные шаблоны: Стандартный анализ обстановки / Паводковый анализ / Краткая сводка для руководства / Сравнительный анализ двух периодов. Пользователи могут создавать собственные промпты под любую задачу, редактировать и хранить их для повторного использования.

ИИ получает в контексте весь массив данных: суммарный дебит, статусы всех точек, горизонты, домены, борта, цвет воды, полевые наблюдения, сравнение с предыдущим периодом по топ-10 точкам. Это гарантирует, что сгенерированный вывод точно соответствует реальным данным.

5. Цифровизация гидрогеологии в компании RG-Gold

Внедрение платформы является первым шагом к построению цифровой модели гидрогеологической обстановки месторождений компании. Переход от аналогового учёта к структурированной базе данных создаёт фундамент для дальнейшей цифровизации:

  1. Накопление исторической базы — каждый обход автоматически формирует временно́й ряд, пригодный для математического анализа
  2. Стандартизация сбора данных — единый формат записи устраняет разночтения между разными исполнителями
  3. Геопространственная привязка — все данные имеют координатную основу для будущей интеграции с ГГИС
  4. Удалённый доступ — специалисты в офисе и на объекте работают с одними актуальными данными без задержек

6. Развитие ИИ-технологий в компании

Платформа является первым в компании RG-Gold практическим применением ИИ-технологий в гидрогеологической службе. Модуль автоматической отчётности уже сегодня использует языковую модель Claude (Anthropic) для генерации профессиональных выводов на основе реальных данных мониторинга — это не пилот и не концепция, а работающий инструмент в промышленной эксплуатации.

Специалист формулирует задание для ИИ на понятном русском языке — модель интерпретирует данные и возвращает готовый профессиональный текст. Это принципиально снижает порог входа в использование ИИ: никаких технических знаний не требуется.

Накопленная историческая база открывает возможности для следующего уровня применения ИИ:

  • Прогнозирование притоков на основе исторических рядов дебитов и сезонных паттернов
  • Аномалий-детекция — автоматическое выявление нетипичных изменений дебита
  • Цифровой двойник — интеграция с геологической моделью для динамической гидрогеологической модели карьера

7. Развитие гидрогеологов в компании

Платформа создаёт новые компетенции для специалистов:

  • Аналитическое мышление: работа с интерактивной аналитикой формирует навык интерпретации трендов вместо механического сбора данных
  • Цифровые компетенции: освоение современных инструментов геоданных и ИИ повышает квалификационный уровень
  • Рост экспертизы: автоматизация рутины высвобождает время для содержательного анализа и рекомендаций
  • Прозрачность результатов: гидрогеолог имеет инструмент для наглядного представления своей работы руководству
