Предложения по редизайну отчёта v2

Анализ текущих проблем и три концепции нового дизайна. Выберите понравившийся стиль — и он будет реализован с исправлением всех трёх багов.

🐛 Найденные баги

Критично
Фотографии не отображаются
Функция fetchPhotoAsBase64 ищет ID Google Drive (/d/ID), но фото хранятся в Supabase Storage — URL не совпадает, функция возвращает null.
→ Добавить прямую загрузку через fetch() для Supabase URL, сохранять base64 в кэш
Важно
Динамика точек не считается
В режиме «одна дата» ptHistory не загружается заранее. buildPointHistoryChart получает пустой массив → delta = null везде.
→ Загружать историю перед генерацией отчёта, передавать в buildPointCard напрямую
Важно
Логотип обрезается в круг
CSS: border-radius:50%; object-fit:cover; width:64px; height:64px — прямоугольные логотипы обрезаются, пропорции нарушаются.
→ Сменить на max-height:80px; width:auto; border-radius:8px с сохранением пропорций

📐 Что меняем в структуре

  • Титульная страница — логотип прямоугольный, правильные пропорции
  • KPI-блок — крупные цифры, иконки, тренд-стрелки
  • Карточки точек — фото слева, метрики справа, мини-график
  • Динамика — отдельная колонка с цветным Δ и % изменения
  • Разделы по доменам — компактнее, без дублирования данных
  • Подвал — номер страницы, дата, версия, имя автора
  • Печать — оптимизированные @page, page-break-inside:avoid

🎨 Три варианта дизайна

  • A — Технический документ: тёмная шапка, белое тело, KPI-строка, таблицы в инженерном стиле. Универсально.
  • B — Дашборд: светлый фон, цветные карточки, иконки, современный UI. Для презентаций руководству.
  • C — Геологический протокол: serif-шрифт, рамки, гриф, ГОСТ-ish. Для официальных документов и архива.

🐛 Детали багов и способы исправления

Три конкретных проблемы с кодом, причины и готовые патчи.

📷

Баг #1 — Фотографии не загружаются в отчёт

ui-report.js → fetchPhotoAsBase64() → extractDriveFileId()
Критично

Причина

// Текущий код ищет только Google Drive URLs:
function extractDriveFileId(url) {
  var m = url.match(/\/d\/([^/?&]+)/);
  return m ? m[1] : null;  // null для Supabase!
}

function fetchPhotoAsBase64(url) {
  var fileId = extractDriveFileId(url);
  if (!fileId) return Promise.resolve(null);
  // ← сразу null, фото не грузится
  return Api.getImage(fileId)...
}

// URL из Supabase выглядит как:
// https://xxx.supabase.co/storage/v1/object/
//   public/photos/IMG_001.jpg

Исправление

function fetchPhotoAsBase64(url) {
  if (!url) return Promise.resolve(null);

  // Supabase Storage URL — загружаем напрямую
  if (url.includes('supabase.co') ||
      url.includes('supabase.in')) {
    return fetch(url)
      .then(function(r) { return r.blob(); })
      .then(function(blob) {
        return new Promise(function(res) {
          var fr = new FileReader();
          fr.onload = function(){ res(fr.result); };
          fr.readAsDataURL(blob);
        });
      }).catch(function(){ return null; });
  }

  // Google Drive — как раньше
  var fileId = extractDriveFileId(url);
  if (!fileId) return Promise.resolve(null);
  return Api.getImage(fileId)...
}

Баг #2 — Динамика точек (Δ) не отображается

ui-report.js → buildPointCard() → ReportState.ptHistory
Важно

Причина

// ptHistory заполняется внутри buildPointHistoryChart,
// но история загружается только если includeHistory=true.
// В режиме single — pa=null, delta=null везде.

// generateReport() НЕ загружает историю отдельно:
mapPromise.then(function(mapImgs) {
  // история не загружается здесь!
  if (s.includePhotos) { ... }
  ...
}).then(function() {
  // ReportState.ptHistory = {} — ПУСТО
  var html = buildReportHTML(s);
});

Исправление

// Добавить загрузку истории ДО генерации отчёта
mapPromise
  .then(function(mapImgs) { ... })
  .then(function() {
    // Загружаем историю для delta-расчётов
    return loadPointHistoryForReport(
      ReportState.ptsB,
      s.dateB
    );
  })
  .then(function() { ... buildReportHTML(s) ... });

function loadPointHistoryForReport(pts, currentDate) {
  if (!pts.length) return Promise.resolve();
  var nums = pts.map(function(p){return p.pointNumber;});
  return Api.getPointHistory(nums, currentDate)
    .then(function(hist) {
      ReportState.ptHistory = hist || {};
    }).catch(function(){ return; });
}

Баг #3 — Логотип обрезается в круг

ui-report.js → getReportCSS() → .rp-title-logo-img
Визуальный

Причина

// В getReportCSS():
'.rp-title-logo-img { ' +
  'width:64px;' +
  'height:64px;' +
  'border-radius:50%;' +    ← круг!
  'object-fit:cover;' +  ← обрезает
  'margin:0 auto 14px;' +
  'display:block;' +
  'border:2px solid ' + c.border +
'}'

// Результат: любой прямоугольный логотип
// (например 300×100px) обрезается в круг 64×64

Исправление

// Заменить правило на пропорциональное:
'.rp-title-logo-img { ' +
  'max-width:200px;' +
  'max-height:80px;' +
  'width:auto;' +
  'height:auto;' +
  'border-radius:8px;' +   ← мягкое
  'object-fit:contain;' + ← вмещает
  'margin:0 auto 16px;' +
  'display:block;' +
'}'

// Логотип теперь показывается в своих пропорциях,
// вписанный в прямоугольник 200×80px
